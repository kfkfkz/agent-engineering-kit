# 跨 Agent 任务交接

交接是可核验的上下文，不是新的权威规范。接手者必须以当前源码、版本状态、项目指令和既有 spec 为准。

## 何时使用

任务未完成但需要换 Agent/会话、等待外部权限或决策、长任务达到清晰阶段边界时使用。已完成的普通汇报无需另造 handoff 文档。

优先把交接状态写入项目已有 tasks/spec/issue/任务系统；没有持久载体时才在对话中输出。除非项目明确要求，不创建与现有计划并行的交接文件。

## 交接契约

```text
目标与不做事项：
当前状态：已完成 / 进行中 / 未开始
关键证据与决策：来源、文件、符号或命令
修改文件：本次改动与用户原有改动分开
验证：已运行命令、结果、未运行原因
剩余工作：按依赖顺序
阻塞与所需权限/人工选择：
风险与不可丢失假设：
唯一下一步：接手后第一个可执行动作
```

不得声称未执行的验证、提交或推送已完成；不得复制密钥、令牌、个人数据或大段日志。临时路径、进程和外部资源若仍有效，要说明生命周期和恢复方式。接手后先验证版本状态、关键文件和失败现场，再继续执行，不能盲信交接摘要。
