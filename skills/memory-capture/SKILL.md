# 记忆捕获

绑定用户指定的仓库。未指定时核对当前项目根。目标须同时有 `.repo-memory-kit/manifest.json` 与 `docs/memory/RULES.md`。专用工作区入口可通过技能真实路径确认所属仓库。目标仍不唯一时先确认。

用户说「记一下」或任务收尾时，按目标 `docs/memory/RULES.md` 的「触发与捕获」「条目格式」及适用的「功能蒸馏清单」提取候选。代码声明的第一次结构检索必须用 `codebase-memory`。复用当前有效的图谱证据。

在对话展示类型、标题、一句话和证据，用户确认后才写文件。模块、frontmatter 与业务域地图的归档规则由 RULES 定义。排除凭证、内网地址和真实个人信息。无法判断敏感性时先核实。

入库后运行 `memory-build` 刷新索引与锚点。如达到画像蒸馏门槛，提示另行蒸馏。
